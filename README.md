# Черновая версия сайта наружной рекламы

Превью оформления: все 27 страниц на месте — работает меню, хлебные крошки и переходы,
в первом экране крутится объёмный логотип. Вместо содержания на внутренних страницах
стоит одинаковая заглушка: скелет вёрстки и перечень того, что появится в рабочей версии.

Открыть: https://andrei-khitrov.github.io/vyveski-draft/

Полная версия с контентом — https://andrei-khitrov.github.io/vyveski-demo/

Черновик закрыт от индексации (`noindex` + `Disallow: /`). Исходники генератора и рабочие
материалы лежат отдельно и в публикацию не выкладываются.
